# ติดตั้งด้วย AI Agent (แนะนำ — ใช้เวลา ~20 นาที)

วิธีนี้คุณ **ไม่ต้องเขียนโค้ดเลย** แค่คุยกับ AI แล้วทำตามที่มันบอก
ระบบนี้มีไฟล์ `CLAUDE.md` ที่เขียนไว้ให้ AI อ่านแล้วรู้วิธีติดตั้งทั้งหมด

## สิ่งที่ต้องมีก่อน

| อย่าง | ได้จากไหน | ฟรีไหม |
|---|---|---|
| บัญชี Cloudflare | https://dash.cloudflare.com/sign-up | ฟรี |
| บัญชี LINE Developers | https://developers.line.biz/console/ | ฟรี |
| Node.js 20 ขึ้นไป | https://nodejs.org | ฟรี |
| AI coding agent | Claude Code / Cursor / Codex / Gemini CLI | มีทั้งฟรีและเสียเงิน |

> **แผนฟรีของ Cloudflare พอใช้จริง**: Workers 100,000 request/วัน และ D1 อ่านได้ 5 ล้านแถว/วัน
> ทีมขนาด 10-20 คนใช้ไม่ถึงเพดานแน่นอน

## ขั้นที่ 2 — เปิด AI agent ในโฟลเดอร์นี้

เช่น ถ้าใช้ Claude Code ก็พิมพ์ `claude` ในเทอร์มินัลที่อยู่ในโฟลเดอร์นี้

## ขั้นที่ 3 — วางคำสั่งนี้ให้ AI

> ช่วยติดตั้งระบบนี้ให้ผมหน่อย อ่าน `CLAUDE.md` ก่อนแล้วพาผมทำทีละขั้น
> ผมยังไม่ได้สร้างอะไรใน LINE และ Cloudflare เลย บอกผมทีละขั้นว่าต้องไปกดอะไรที่ไหน
> ขั้นไหนที่คุณรันคำสั่งแทนผมได้ก็รันเลย ขั้นไหนที่ผมต้องทำเองบอกให้ชัด

AI จะพาคุณไล่ตามนี้ (ถ้ามันข้ามขั้นไหนไป ให้ทักได้):

1. ตรวจ Node/ติดตั้ง dependency/ล็อกอิน Cloudflare
2. **บอกให้คุณไปสร้าง 2 channel ที่ LINE Developers** แล้วขอค่ามาจากคุณ
3. สร้างฐานข้อมูล D1 + สร้างตาราง + deploy ครั้งแรก → ได้ URL ของระบบ
4. **บอกให้คุณสร้าง LIFF app** ด้วย URL ที่ได้ แล้ว deploy ซ้ำ
5. **บอกให้คุณตั้ง Webhook** แล้วช่วยทดสอบว่าลายเซ็นผ่าน
6. ติดตั้งริชเมนู + ใส่ข้อมูลเริ่มต้น

## ขั้นที่ 4 — สิ่งที่คุณต้องไปกดเองบนเว็บ (AI ทำแทนไม่ได้)

AI เข้าเว็บ LINE Developers แทนคุณไม่ได้ ตรงนี้ต้องทำเอง 3 จุด

### 4.1 สร้าง Messaging API channel (ตัวบอท)

1. เข้า https://developers.line.biz/console/ → **Create a new provider** (ตั้งชื่ออะไรก็ได้)
2. ในโปรไวเดอร์นั้น → **Create a Messaging API channel**
3. กรอกชื่อบอท (เช่น "คลังสินค้า") รูปโปรไฟล์ ประเภทธุรกิจ
4. เข้าไปที่ channel ที่สร้าง แล้วเก็บค่า 2 ตัวนี้ไว้ให้ AI:
   - แท็บ **Basic settings** → **Channel secret**
   - แท็บ **Messaging API** → **Channel access token (long-lived)** → กด **Issue**
5. ยังอยู่แท็บ Messaging API → เลื่อนหา **Auto-reply messages** และ **Greeting messages** → กด **Edit** → **ปิดทั้งคู่**
   (ถ้าไม่ปิด บอทจะตอบข้อความอัตโนมัติซ้อนกับคำตอบจริง)

### 4.2 สร้าง LINE Login channel + LIFF app

1. ในโปรไวเดอร์เดิม → **Create a LINE Login channel**
2. แท็บ **Basic settings** → เก็บ **Channel ID** (ตัวเลข 10 หลัก) ไว้ให้ AI
3. แท็บ **LIFF** → **Add**
   - **Size:** `Full`
   - **Endpoint URL:** URL ที่ AI ได้จากการ deploy (เช่น `https://line-stock.xxxx.workers.dev`)
   - **Scopes:** ติ๊ก `profile` **และ** `openid` ← **ขาด `openid` แล้วล็อกอินไม่ผ่าน**
   - **Scan QR:** เปิด (ใช้สแกนบาร์โค้ดสินค้า)
4. เก็บ **LIFF ID** (หน้าตาเช่น `1234567890-abcdefgh`) ไว้ให้ AI

### 4.3 ตั้ง Webhook

กลับไปที่ Messaging API channel → แท็บ **Messaging API** → **Webhook settings**
- **Webhook URL:** `<URL ของคุณ>/line/webhook`
- กด **Verify** → ต้องขึ้น **Success**
- เปิดสวิตช์ **Use webhook**

## ขั้นที่ 5 — ทดสอบ

1. แท็บ Messaging API มี QR code ของบอท → สแกนเพื่อแอดเป็นเพื่อน
2. พิมพ์ `ช่วยเหลือ` → ต้องได้การ์ดวิธีใช้
3. พิมพ์ `เบิก ปากกา 5` → ต้องได้การ์ดให้เลือกคลัง แล้วการ์ดยืนยัน
4. กดปุ่ม **แดชบอร์ด** ที่ริชเมนู → หน้าเว็บต้องเปิดในแอป LINE

ถ้าติดตรงไหน บอก AI ว่า *"ติดขั้นนี้ ขึ้น error แบบนี้"* แล้ววาง error ให้ดู
ใน `CLAUDE.md` มีตารางอาการเสียที่พบบ่อยพร้อมสาเหตุอยู่แล้ว AI จะแก้ให้ได้

## ขั้นที่ 6 — สั่ง AI ปรับแต่งต่อได้เลย

พอระบบเดินได้แล้ว ลองสั่งพวกนี้ดู:

> เพิ่มคำสั่ง "คืนของ" ให้ทำงานเหมือน "รับเข้า" แต่บันทึกหมายเหตุว่าเป็นการคืน

> เปลี่ยนสีธีมแดชบอร์ดเป็นโทนน้ำเงิน

> เพิ่มฟิลด์ "ราคาต่อหน่วย" ในสินค้า แล้วโชว์มูลค่าสต๊อกรวมในหน้าภาพรวม

> ทำให้บอทส่งข้อความเตือนทุกเช้า 8 โมง ถ้ามีสินค้าต่ำกว่าจุดสั่งซื้อ

> เพิ่มการแยกสิทธิ์ ให้เฉพาะ LINE User ID ที่กำหนดเท่านั้นที่แก้ข้อมูลสินค้าได้

ตาราง *"จุดที่มักถูกขอให้แก้ และควรแก้ที่ไหน"* ใน `CLAUDE.md` จะช่วยให้ AI แก้ถูกที่
ไม่รื้อโค้ดมั่ว

## คำเตือนเรื่องความปลอดภัย

- **อย่า commit ไฟล์ `.dev.vars` ขึ้น GitHub** (มี `.gitignore` กันไว้แล้ว อย่าไปแก้)
- **อย่าวาง Channel access token ในที่สาธารณะ** เช่น คอมเมนต์ YouTube หรือ issue บน GitHub
- ถ้าเผลอหลุด → เข้า LINE Console กด **Reissue** token ใหม่ทันที ของเก่าจะใช้ไม่ได้
- ระบบนี้ **ไม่แยกสิทธิ์ผู้ใช้** ใครแอดบอทได้ก็ทำรายการได้ ถ้าใช้กับข้อมูลจริง
  แนะนำให้ตั้ง LINE OA เป็นแบบไม่ค้นหาเจอ (ปิด "Allow search by ID") และแจก QR เฉพาะคนในทีม
