# ติดตั้งด้วย AI Agent (ไม่ต้องเขียนโค้ดเป็น)

คู่มือนี้เขียนสำหรับ **คนที่ไม่เคยเขียนโปรแกรม** ใช้เวลาประมาณ 30-40 นาที
คุณจะไม่ต้องเขียนโค้ดเลยแม้แต่บรรทัดเดียว — หน้าที่คุณคือ **คุยกับ AI** และ **ไปกดปุ่มบนเว็บ LINE ตามที่มันบอก**

> 📖 เจอศัพท์ไม่เข้าใจ เปิด [ศัพท์ที่จะเจอ แปลเป็นภาษาคน](GLOSSARY.md) หรือถาม AI ได้เลย

---

## เตรียมตัวก่อนเริ่ม

สมัคร 2 บัญชีนี้ให้เรียบร้อย (ฟรีทั้งคู่ ไม่ต้องผูกบัตร)

| บัญชี | สมัครที่ | ใช้ทำอะไร |
|---|---|---|
| Cloudflare | https://dash.cloudflare.com/sign-up | ที่ฝากระบบให้ทำงานบนอินเทอร์เน็ต |
| LINE Developers | https://developers.line.biz/console/ | สร้างบอทและหน้าแดชบอร์ด (ล็อกอินด้วยบัญชี LINE ที่ใช้อยู่) |

### เรื่องเงิน — ไม่มีบิลเซอร์ไพรส์

- **Cloudflare แผนฟรี ไม่ต้องใส่บัตรเครดิต** ให้โควตา Workers 100,000 ครั้ง/วัน และฐานข้อมูล D1 อ่าน 5 ล้านแถว/วัน
- ทีม 10-30 คนใช้ไม่ถึงเพดานแน่นอน (การเบิกของ 1 ครั้ง ≈ ใช้ไม่กี่ request)
- **ถ้าใช้เกินโควตา ระบบจะหยุดให้บริการชั่วคราวจนถึงเที่ยงคืน ไม่ใช่เรียกเก็บเงินเพิ่ม**
- LINE Messaging API: ข้อความที่บอท**ตอบกลับ**ผู้ใช้ (reply) ฟรีไม่จำกัด ระบบนี้ใช้แต่ reply

## ขั้นที่ 1 — ติดตั้ง OpenCode

[OpenCode](https://opencode.ai) เป็น AI coding agent แบบโอเพนซอร์ส มีเวอร์ชัน **desktop app** ที่ติดตั้งแบบดับเบิลคลิก
และอ่านไฟล์ `AGENTS.md` ของโปรเจกต์นี้ได้เลยโดยไม่ต้องตั้งค่าอะไร

1. เข้า **https://opencode.ai/download** → โหลดเวอร์ชันของเครื่องคุณ (macOS / Windows / Linux)
2. ติดตั้งเหมือนโปรแกรมทั่วไป
3. เปิดโปรแกรม → ล็อกอินเลือกวิธีใช้โมเดล AI อย่างใดอย่างหนึ่ง:
   - **OpenCode Zen** — โมเดลที่ทีม OpenCode คัดมาให้ (ง่ายสุดสำหรับมือใหม่)
   - **ChatGPT Plus/Pro** หรือ **GitHub Copilot** — ถ้าสมัครอยู่แล้ว ใช้ของเดิมได้
   - **API key ของตัวเอง** — ถ้ามีอยู่แล้ว

> ℹ️ OpenCode desktop ยังเป็นเวอร์ชัน beta ถ้าเจอบั๊กของตัวโปรแกรมเอง ใช้เวอร์ชันเทอร์มินัลแทนได้
> (หรือจะใช้ Cursor / Claude Code / Codex ก็ได้เหมือนกัน ทุกตัวอ่าน `AGENTS.md` ของเราได้)

## ขั้นที่ 2 — สั่งงาน AI ด้วยประโยคเดียว

เปิด OpenCode แล้ว **ก๊อปข้อความทั้งก้อนนี้ไปวาง** แล้วกด Enter

```text
ช่วยติดตั้งระบบจัดการสต๊อกผ่าน LINE ให้ผมหน่อยครับ

โปรเจกต์อยู่ที่ https://github.com/ManageWithNoobItGuy/line-stock-bot
ให้ clone ลงมาในเครื่องผมก่อน แล้วอ่านไฟล์ AGENTS.md ในนั้นให้จบ
จากนั้นพาผมติดตั้งทีละขั้นตามที่เขียนไว้

ข้อมูลของผม:
- ผมเขียนโปรแกรมไม่เป็น อธิบายด้วยภาษาคนธรรมดา อย่าใช้ศัพท์เทคนิคลอย ๆ
- ผมยังไม่ได้สร้างอะไรใน LINE และ Cloudflare เลย
- ขั้นไหนที่คุณรันคำสั่งแทนผมได้ ให้รันเลย
- ขั้นไหนที่ผมต้องไปกดเองบนเว็บ ให้บอกชัด ๆ ว่าเข้าเว็บไหน กดปุ่มชื่ออะไร อยู่ตรงไหนของหน้า
  แล้วรอผมตอบว่าทำเสร็จแล้วก่อนไปขั้นถัดไป
- ถ้าต้องใช้ค่าอะไรจากผม ให้ถามทีละค่า
```

AI จะเริ่มทำงานให้ทันที ตั้งแต่โหลดโปรเจกต์ ตรวจเครื่อง ติดตั้งของที่ต้องใช้
ไปจนถึงสร้างฐานข้อมูลและส่งระบบขึ้นใช้งานจริง

## ขั้นที่ 3 — สิ่งที่คุณต้องไปกดเองบนเว็บ LINE (AI ทำแทนไม่ได้)

AI เข้าเว็บ LINE Developers แทนคุณไม่ได้ ตรงนี้มี 3 จุด **AI จะบอกคุณเองว่าถึงคิวไหนแล้ว**
ส่วนนี้เก็บไว้เปิดดูประกอบ

### 3.1 สร้าง Messaging API channel (ตัวบอท)

1. เข้า https://developers.line.biz/console/
2. กด **Create a new provider** → ตั้งชื่อ (ชื่อบริษัท/ทีมก็ได้) → **Create**
3. กด **Create a Messaging API channel** → กรอกชื่อบอท (เช่น "คลังสินค้า") รูป และประเภทธุรกิจ → สร้าง
4. เข้าไปในช่องที่สร้าง แล้วเก็บ 2 ค่านี้ไปให้ AI:
   - แท็บ **Basic settings** → เลื่อนหา **Channel secret** → กด Copy
   - แท็บ **Messaging API** → เลื่อนหา **Channel access token (long-lived)** → กด **Issue** → Copy
5. **ยังอยู่แท็บ Messaging API** → เลื่อนหา **Auto-reply messages** และ **Greeting messages**
   → กด **Edit** ทีละอัน → **ปิดทั้งคู่**
   *(ถ้าไม่ปิด บอทจะตอบข้อความสำเร็จรูปซ้อนกับคำตอบจริง)*

### 3.2 สร้าง LINE Login channel + LIFF

1. กลับไปหน้า provider เดิม → **Create a LINE Login channel** → กรอกข้อมูล → สร้าง
2. แท็บ **Basic settings** → เก็บ **Channel ID** (ตัวเลข 10 หลัก) ไปให้ AI
3. แท็บ **LIFF** → **Add** → กรอกตามนี้:

   | ช่อง | ใส่อะไร |
   |---|---|
   | LIFF app name | ตั้งชื่ออะไรก็ได้ เช่น "แดชบอร์ดสต๊อก" |
   | Size | **Full** |
   | Endpoint URL | **URL ที่ AI ให้มาหลัง deploy** (เช่น `https://line-stock.xxxx.workers.dev`) |
   | Scopes | ติ๊ก **`profile`** และ **`openid`** ← ขาด `openid` แล้วล็อกอินไม่ผ่าน |
   | Scan QR | **เปิด** (ใช้สแกนบาร์โค้ดสินค้า) |

4. เก็บ **LIFF ID** (หน้าตาเช่น `1234567890-abcdefgh`) ไปให้ AI

### 3.3 เปิด Webhook

กลับไปที่ Messaging API channel → แท็บ **Messaging API** → หัวข้อ **Webhook settings**

1. **Webhook URL** ใส่ URL ที่ AI ให้มา แล้วต่อท้ายด้วย `/line/webhook`
2. กด **Verify** → ต้องขึ้น **Success** *(บอก AI ได้ ให้มันทดสอบให้ก่อนคุณกด)*
3. เปิดสวิตช์ **Use webhook**

## ขั้นที่ 4 — เช็กว่าสำเร็จหรือยัง

ไล่ติ๊กทีละข้อ ถ้าข้อไหนไม่ผ่าน บอก AI ว่า "ติดข้อนี้" ได้เลย

- [ ] AI บอก URL ของระบบมาแล้ว เช่น `https://line-stock.xxxx.workers.dev`
- [ ] เปิด URL นั้นในเบราว์เซอร์ แล้วเห็นหน้าเว็บ (จะขึ้นว่าให้เข้าผ่าน LINE — ถือว่าถูกแล้ว)
- [ ] กด **Verify** ที่ Webhook settings แล้วขึ้น **Success**
- [ ] แอดบอทเป็นเพื่อน (สแกน QR ในแท็บ Messaging API)
- [ ] พิมพ์ `ช่วยเหลือ` หาบอท → **ได้การ์ดวิธีใช้กลับมา** ← ข้อนี้ผ่าน = บอทใช้งานได้แล้ว
- [ ] พิมพ์ `สรุป` → ได้การ์ดภาพรวมตัวเลข
- [ ] พิมพ์ `เบิก ปากกา 5` → ได้การ์ดให้เลือกคลัง แล้วการ์ดยืนยัน
- [ ] กดปุ่ม **แดชบอร์ด** ในริชเมนู (หรือเปิด `https://liff.line.me/<LIFF ID ของคุณ>`)
      → **หน้าแดชบอร์ดเปิดในแอป LINE** ← ข้อนี้ผ่าน = ครบทั้งระบบ

ผ่านหมด = เสร็จแล้ว 🎉 อ่านวิธีใช้งานต่อได้ที่ [คู่มือการใช้งาน](USAGE.md)

## ถ้าติดปัญหา

### วิธีบอก AI ให้ช่วยได้ผลที่สุด

**อย่าพิมพ์แค่ว่า "ไม่ได้" หรือ "พัง"** ให้บอก 3 อย่างนี้:

```text
ผมติดที่ขั้นตอน [ชื่อขั้นตอน]
ผมทำ [สิ่งที่ทำ] แล้วขึ้นแบบนี้:

[ก๊อปข้อความ error ทั้งก้อนมาวาง]
```

ยิ่งวางข้อความ error มาทั้งก้อน AI ยิ่งแก้ถูกจุด — **ไม่ต้องกลัวว่ามันยาวเกินไป**

### AI แก้แล้วยิ่งพัง / อยากเริ่มใหม่หมด

ระบบนี้รื้อทิ้งแล้วเริ่มใหม่ได้ ไม่เสียหายอะไร บอก AI ว่า:

```text
ผมอยากเริ่มติดตั้งใหม่ทั้งหมด ช่วยลบ Worker และฐานข้อมูล D1 ที่สร้างไว้
แล้วเริ่มกระบวนการติดตั้งใหม่ตั้งแต่ต้นให้หน่อย
```

ส่วนฝั่ง LINE **ไม่ต้องลบ** ใช้ channel เดิมได้เลย แค่แก้ Endpoint URL กับ Webhook URL ให้เป็นของใหม่

> ⚠️ ถ้าใส่ข้อมูลสินค้าจริงไปแล้ว ให้สั่ง AI สำรองข้อมูลก่อน:
> *"ช่วย export ข้อมูลในฐานข้อมูลออกมาเก็บไว้ก่อนลบ"*

## 3 ข้อห้าม (สำคัญมาก)

1. **ห้ามเอา Channel access token หรือ Channel secret ไปโพสต์ที่สาธารณะ** — คอมเมนต์ YouTube, กลุ่ม Facebook, GitHub issue
   ถ้าเผลอหลุด → เข้า LINE Console กด **Reissue** ออกตัวใหม่ทันที ของเก่าจะใช้ไม่ได้
2. **ห้ามอัปไฟล์ `.dev.vars` ขึ้น GitHub** — โปรเจกต์มีตัวกันไว้แล้ว ถ้า AI จะแก้ไฟล์ `.gitignore` ให้ห้ามไว้
3. **ห้ามให้ AI ปิดการตรวจลายเซ็น webhook** เพื่อ "ให้มันผ่าน ๆ ไป" — นั่นคือประตูที่กันคนอื่นยิงคำสั่งปลอมเข้าระบบคุณ
   ถ้าติดตรงนั้น ให้แก้ที่ต้นเหตุคือ Channel secret ไม่ตรง

## ปรับแต่งต่อได้เลย

พอระบบเดินได้แล้ว สั่ง AI ต่อได้ทันที เช่น

> เปลี่ยนสีธีมแดชบอร์ดเป็นโทนน้ำเงิน

> เพิ่มคำสั่ง "คืนของ" ให้ทำงานเหมือนรับเข้า แต่บันทึกหมายเหตุว่าเป็นการคืน

> เพิ่มฟิลด์ราคาต่อหน่วยในสินค้า แล้วโชว์มูลค่าสต๊อกรวมในหน้าภาพรวม

> ทำให้บอทส่งสรุปของใกล้หมดเข้ากลุ่มทุกเช้า 8 โมง

> เพิ่มการแยกสิทธิ์ ให้เฉพาะคนที่กำหนดเท่านั้นที่แก้ข้อมูลสินค้าได้

ในไฟล์ `AGENTS.md` มีตารางบอกไว้แล้วว่าฟีเจอร์ไหนต้องแก้ไฟล์ไหน AI จะแก้ถูกที่โดยไม่รื้อโค้ดมั่ว
